# SmartPay GymFlex page prototype

Switchable prototype of the SmartPay GymFlex benefit page for comparative testing.

- **Version A** (`?view=a`): the current GymFlex page.
- **Version B** (default): the proposed redesign.

The switch in the bottom-left corner flips between them and isn't part of either design.

Built with Vite + React, reusing the header, footer and UI components from
[smartpay-benefits-landing-prototype](https://github.com/DaveGeorgeDesign/smartpay-benefits-landing-prototype).

```sh
npm install
npm run dev
```

Pushing to `main` rebuilds the GitHub Pages site.
